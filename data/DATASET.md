Side-chain macrocycles are subtyped from their crosslink atoms (`cyclization.subtype_sidechain`):

### Enriched features (`complex_features.parquet`, merged into `structure_all`)
Per complex, from the native structure: **peptide secondary structure** (P-SEA: 5477 coil /
925 helix / 531 sheet) and **interface size** (5 Å heavy-atom contacts; median 28 residues).
Biologically consistent — staples are predominantly helical; cyclic peptides bury less interface.

### Target class (`complex_target_class.parquet`, heuristic)
Receptor functional class by keyword on the RCSB entity description (MHC, antibody, protease,
kinase, ubiquitin-system, phosphatase, SH2/SH3, integrin, GPCR, …; large `other` bucket).
Coarse but analytically useful and biologically coherent (MHC binds only linear peptides).

### Leakage control + splits (`leakage.parquet`)
- 6933 complexes → mmseqs2 receptor (1417) + peptide (5102) clusters; time tiers vs
  AF2/AF3/2023/2024 cutoffs.
- **Three ready-to-use train/test families** (deterministic, hash-based): `split_random`
  (~80/20), `split_homology` (5644/1289 — **no receptor cluster spans train+test**,
  QC-enforced), `split_time` (6838/95 — post-2024 novel-receptor, leakage-free).
- Validated: 3av*/7k2* binder series collapse to single receptor clusters.

## Cyclic monomers (80)  — cyclic-structure-prediction sub-track
63 bicyclic (head-to-tail + disulfide) + 17 head-to-tail. Detector agrees with the source's
hand-curated modes 80/80. Legacy pre-2020 PDB (training-contaminated; capability comparison
only, not novelty claims).

## Affinity (1995)  — Track C
**1995 distinct measurements** over 629 complexes (427 peptides, 485 PDBs); length 8–50
(median 13); log10 Kd −12.9 .. −2.5 (pM→mM, ~10 orders). Sources: SKEMPI (mutational), PDBbind,
SAbDab, ATLAS, Affinity Benchmark. Within-track deduped (6 exact dups dropped); SKEMPI
mutational variants kept as distinct rows with unique ids (`__m0/__m1…`; `notes` carries
`src=`+`mut=`). Structure-labeled cyclization → 73 cyclic rows (68 disulfide / 4 staple /
1 thioether), 66 ncAA.

## Non-canonical complexes (885 in the mine; 2226 ncAA total)  — ncAA axis
The dedicated PDB ncAA mine (`ingest_pdb_ncaa.py`, search by CCD code) contributes 885
modified-residue complexes; combined with PepBench the structure set has **2226 ncAA** total. This count is re-derived from the deposited structures: a residue is non-canonical if its own three-letter code is not one of the twenty standard ones, which the previous count decided by whether the residue mapped to a one-letter code. The pre-repair value 1,877 is retained per complex as `has_ncaa_orig`.
Top chemistries: D-Ala, hydroxyproline, N-Me-Val/Leu, sarcosine, norleucine, Aib, cyclosporin's
BMT. Side-chain macrocycles are subtyped (thioether/ester/lactam/staple), not left as `other`.

## Interaction (19,187)  — Track D
TPepPro balanced pairs (9594 pos / 9593 neg), 7892 receptors / 5643 peptides, length 2–50.

## Cyclization detector (validated)
`scripts/curate/cyclization.py` fuses struct_conn + geometry (N-term↔C-term distance for
head-to-tail; SG–SG for disulfide). Validations: 1SFI→bicyclic (SFTI-1, correct); 80/80
agreement with hand-curated monomer modes; head-to-tail false-positive (explicit peptide-bond
covale records) caught and fixed on PepPCBench.

## Within-track dedup (and intentional cross-track overlap)
- **Structure**: deduped by (pdb, chain) across all 5 sources → 6933 unique complexes (0 dups).
- **Affinity**: 6 exact-dup rows dropped; mutational variants kept with unique ids.
- **Interaction**: unique by (receptor_id, peptide_id, label).
- **Across tracks the same complex may recur** — by design (a complex can be a structure task,
  an affinity task, and an interaction task). 172 PDBs overlap structure↔affinity, 3087
  structure↔interaction. QC enforces uniqueness *within* each track only.
