Data for Bhargava, “PepArena: A Leakage-Aware Benchmark for Peptide–Protein Structure, Affinity, and Interaction Prediction.”
This archive contains the dataset manifests and leakage-aware splits, native reference complexes, top-ranked predicted poses, shared alignments and cached embeddings, and per-complex scores reported in the manuscript.
Additional materials are available on request at [yash@bhargavaresearch.org](mailto:yash@bhargavaresearch.org).
Code repository: [https://github.com/Bhargava-Systems-Research-Inc/PepArena](https://github.com/Bhargava-Systems-Research-Inc/PepArena)
