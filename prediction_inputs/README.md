# Track A — cofolding prediction inputs (605 → 559 foldable post-2023-06-01 set)

Generated by `scripts/run/track_a/prepare_inputs.py` from the fold-list. One folder per model,
one file per complex (`<complex_id>.<ext>`), in each model's native format. Receptor chains are
written as **separate** chains (A, B, …); the peptide is the last chain; cyclization is encoded
as bonds where the format supports it.

| folder | format | cyclization input |
|---|---|---|
| `af3/`, `highfold3/` | AlphaFold3 JSON | `bondedAtomPairs` (disulfide SG–SG, head-to-tail N..C, side-chain crosslinks) |
| `helixfold3/` | AF3-style JSON | same (HF3 ingests AF3 format) |
| `protenix/` | Protenix JSON (list) | `covalent_bonds` (left/right) |
| `boltz2/` | Boltz YAML | `constraints: - bond` |
| `chai1/`, `esmfold2/`, `rfaa/` | FASTA | sequences only (bond input not standard) |

`inputs_manifest.csv` flags every complex: `n_receptor_chains, peptide_len, n_bonds,
is_cyclic, cyclization_type, has_ncaa`.

## WARN Two tiers — read before running

These 559 complexes are **not** uniformly fold-ready:

**1. Canonical (334) — fold-ready for all 8 models.**
321 linear + 13 cyclic (7 disulfide, 5 head-to-tail, 1 thioether). Sequences are valid; the
13 cyclics carry correct bonds (12/13). → 334 × 8 = **2,672 predictions**, clean and fair.

**2. Non-canonical (225) — need CCD-level inputs (NOT yet usable as-is).**
134 linear + 91 cyclic — and this is where the **cyclization-chemistry diversity lives**:
lactam 20, staple 14, thioether 12, ester 4, plus 29 head-to-tail and 12 disulfide. Their
peptides contain non-canonical residues, currently written as `X` in the sequence, which:
- general models (AF3/Boltz/Chai) cannot fold meaningfully, and
- breaks the side-chain bond mapping (the crosslink often lands on the dropped ncAA residue).

**Implication:** the headline cyclic-chemistry benchmark *requires* proper per-residue CCD
inputs for these 225. That's feasible for the **ncAA-capable** models — **AF3, Protenix,
Boltz-2, HighFold3** (all support CCD `modifications`/`covalent_bonds`) — but not for ESMFold2 /
Chai (single-seq) / RoseTTAFold-AA. So the cyclic-chemistry tier is naturally a 4-model
sub-track. Building those CCD inputs is the next step (`prepare_inputs.py` will gain a
`--ncaa-ccd` mode that reads per-residue CCD codes from the native structure).

## Recommended run plan
- **Tier 1 (now):** canonical 334 × 8 models = 2,672 folds — the standard post-cutoff
  peptide-protein cofolding comparison.
- **Tier 2 (after CCD inputs):** ncAA 225 × {AF3, Protenix, Boltz-2, HighFold3} = ~900 folds —
  the novel leakage-clean cyclic-chemistry benchmark.
